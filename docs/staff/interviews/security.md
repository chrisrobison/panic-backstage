# Security Interview Worksheet

Use this to interview current/experienced security staff to fill the TODOs in the Security SOP
and Venue Safety/Emergency documents.

## Core questions

1. What are you responsible for on a shift?
2. What decisions can you make without checking with anyone else?
3. What requires manager approval before you can act?
4. What can get someone hurt if this role is done wrong?
5. What can get the venue in legal or regulatory trouble if this role is done wrong?
6. What can cost the venue significant money if this role is done wrong?
7. What mistakes do new security staff commonly make?
8. What should every security person know on day one?
9. What do you do when you arrive?
10. What do you do during the event?
11. What do you do before leaving?
12. What do you do when something goes wrong?

## Role-specific questions

1. Are you required to hold a BSIS Guard Card, and how is that verified today?
2. What's the actual use-of-force / removal guideline you follow?
3. What's your real process for a physical altercation, start to finish?
4. Who do you report incidents to, and how (verbally, written, both)?
5. What's the current escalation point if you believe a weapon is on premises?
